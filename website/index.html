Up and running in a minute

Meteorist is a regular Fabric mod. No installers, no configs, no accounts.

1

Get the base

Install Fabric Loader and Meteor Client. Meteorist runs on top of Meteor, not instead of it.

2

Download the jar

Current build targets the latest Minecraft release. Need another version? Grab an older jar.

3

Drop it in mods

Put meteorist-*.jar into your .minecraft/mods folder and launch the game. Modules appear in the ClickGUI under the Meteorist category.

check_circle Required

  • Java 25 or newer
  • Fabric Loader any recent build
  • Meteor Client matching Minecraft version

add_circle Optional

  • Baritone powers Item Sucker pathfinding
  • Minescript enables Minescript Integration

Hi! I'm Zgoly, the developer behind Meteorist.

It started with a few simple modules I made for myself and my friends to make anarchy servers more fun. Once I put the project on GitHub, other players found it, and it slowly grew into the big open-source toolbox it is today. Questions, answered

Is Meteorist a standalone client?add

No, because it is an add-on for Meteor Client, packaged as a regular Fabric mod. You need to install Meteor first and then drop the Meteorist jar into your mods folder alongside it.

Which Minecraft versions are supported?add

Each jar targets one specific Minecraft version, which you can see right in the release tag. For example, ... is built specifically for .... Meteorist always follows Meteor Client releases, so the current build matches the latest supported version. You can find older jars in the Releases archive.

Where do I find everything in-game?add

To use modules, open the Meteor ClickGUI and look for the Meteorist category. To run commands, simply type them directly into the chat, like .interact. For HUD presets, just add a regular Text element in the HUD editor and paste the snippet, since the values update live via Starscript.

Do I need Baritone or Minescript?add

No, since both of them are completely optional. Baritone is only required if you use the Item Sucker module for pathfinding to items and back. Minescript is only needed if you want to use the Minescript Integration module. Everything else works out of the box.

Is it really free?add

Yes. The full source code is hosted on GitHub under the GPL-3.0 license. Donations exist purely to support development costs.

Can I suggest a module or feature?add

Please do! You can open a suggestion on GitHub or talk about it in my Discord. A lot of existing features actually started out as community ideas.

Something broke. Where do I report it?add

You can open a bug report on GitHub. Please include your Minecraft version, the Meteor and Meteorist versions, and quick steps to reproduce the issue. If the mod crashed, make sure to attach the log file. For quick troubleshooting help, joining the Discord is usually your best bet.

Keep the meteors falling

The mod is free and always will be. If it saved your totem or just made your day, you can support development or simply star the repo. It really helps.
